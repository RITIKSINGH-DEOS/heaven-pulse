## 🏛️ Executive Overview

Modern social platforms reward superficial perfection, trapping millions of students and young professionals in silent epidemics of **impostor syndrome, physical body dysmorphia, social anxiety, and chronic belonging deficiency**. 

When individuals experience acute self-doubt at 2:00 AM, existing solutions fail them catastrophically:
- **Commercial AI Chatbots** feel cold, mechanical, and lonely—leaving users staring at an unfeeling algorithm.
- **Anonymous Forums (e.g. Reddit, Discord)** introduce immediate risks of trolling, creepy direct messages, toxic unsolicited advice, or painful silence (0 replies).
- **Clinical Therapy** carries prohibitive \$150/hr price tags and 6-week campus counseling waitlists.

**HeavenPulse** establishes a new category: **Digital Cognitive Sanctuary Infrastructure**. It unites the evidence-based rigor of **Cognitive Behavioral Therapy (CBT)** with the warmth of **anonymized, live peer resonance**—built with an unyielding zero-trace privacy guarantee.

## 🚨 The Bleeding Crisis & Paradigm Shift

> *"The status quo is broken because traditional digital mental health isolates individuals behind cold AI chat screens or exposes them to toxic social media judgment; **HeavenPulse transforms raw personal insecurity into scientifically grounded cognitive reframing while permanently shattering the illusion of loneliness through zero-knowledge peer resonance.**"*

### The Insecurity Paradox
1. **The Internal Distortion:** The mind invents catastrophic cognitive distortions (*"I am an impostor", "Everyone is judging my face", "My friends secretly resent me"*).
2. **The External Isolation:** The agonizing belief that *"Everyone else is thriving; I am the only broken person in the room."*

HeavenPulse dismantles both layers simultaneously:
- **Phase 1 (Human Solidarity):** Connecting with a verified live peer who is navigating the exact same domain of vulnerability.
- **Phase 2 (Cognitive Liberation):** Socratic deconstruction that exposes the psychological fallacy and anchors the mind in empirical reality.

## 🖥️ Core Product Walkthrough

### 1. The Sanctuary Intake
- **Distraction-Free Zen Canvas:** Deep obsidian black palette (`#000000`) with a 3D animated particle wave mesh and ambient spotlight cone.
- **Domain Selection:** Categorizes vulnerability into 4 clinical archetypes:
  - 🧠 *Impostor & Career*
  - 🪞 *Body & Self-Image*
  - 👥 *Social Inadequacy*
  - 💔 *Belonging & Loneliness*
- **Deterministic Crisis Filter:** Scans input for acute self-harm indicators before any processing, instantly surfacing the National 988 Lifeline.

### 2. The Live Peer Resonance Hub
- **Telemetry Counter:** Demonstrates community solidarity (*"420+ anonymous members processed this exact domain this week"*).
- **Live Peer Cards Grid:** Displays vetted peer struggles with 🟢 **Online Now** glowing pulse indicators and distilled perspective gifts.
- **Direct Solo Bypass:** Introvert-friendly shortcut allowing users who prefer quiet contemplation to skip chat and proceed directly to The Clarity Mirror.

### 3. The 5-Minute Ephemeral Empathy Bridge
- **Anonymous Aliases:** Assigns gentle, nature-inspired pseudonyms (e.g., *You: CalmSeeker*, *Peer: QuietPine*).
- **Focused 5:00 Timer:** Time-bounded conversation prevents cyclical rumination or trauma-dumping.
- **Toxicity & PII Firewall:** Automatically intercepts and redacts phone numbers, email addresses, and social handles (`@instagram`, `whatsapp`, etc.).
- **Empathy Quick Drops:** One-click supportive affirmations (🫂 *Shared Burden*, 🕯️ *Sending Strength*).

### 4. The Clarity Mirror & Release Ritual
- **Distortion Classification:** Accurately diagnoses whether the thought stems from *Mind-Reading, Catastrophizing, Spotlight Trap, or All-or-Nothing thinking*.
- **The Dual-Column Contrast:** Side-by-side comparison contrasting the *Critic's Illusion* against the *Objective Reality Anchor*.
- **Socratic Reflection Prompts:** Evidence-based philosophical challenges to dismantle the negative cognitive loop.
- **4-4-6 Grounding Breath Pacer:** Interactive visual orb pacing Inhale (4s), Hold (4s), and Exhale (6s) for vagal nerve calming.
- **The "Release & Burn" Ritual:** An interactive action where the thought is permanently purged from browser memory, dissolving into light with zero server logs.

## 🔒 Privacy & Zero-Knowledge Security Architecture

HeavenPulse is engineered around an **uncompromising zero-trace threat model**:

1. **Zero Registration / Zero Authentication:** No email, password, OAuth, or phone number is ever requested or accepted.
2. **In-Memory Ephemeral Storage:** Session states exist solely within active React memory and browser `sessionStorage`. Closing the tab or clicking "Release & Burn" permanently purges 100% of data.
3. **Zero Database Writes:** The backend maintains **zero SQL/NoSQL databases** for storing user thoughts or chat logs. There is literally nothing to leak, subpoena, or hack.
4. **Automated PII Neutralization:** All text exchanged in the Empathy Bridge passes through deterministic regex sanitizers that redact contact information in real-time.

## 🚀 Local Quickstart & Verification

Follow these steps to run and verify HeavenPulse locally:

### Prerequisites
- **Node.js:** v18.0.0 or higher (Tested on Node.js v22.16.0)
- **Package Manager:** `npm` (v10+ or v11+)

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/RITIKSINGH-DEOS/heaven-pulse.git
cd heaven-pulse

# 2. Install dependencies
npm install

# 3. Run the automated test suite (100% Passing Verification)
npm test

# 4. Start the local development server
npm run dev
```

Visit **[http://localhost:3000](http://localhost:3000)** in your browser to experience the live application.

### Production Build Verification
```bash
npm run build
npm start
```
